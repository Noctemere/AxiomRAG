# Phase 1 File Guide

## Root files

- `.gitignore`: Keeps virtual environments, build output, secrets, caches, and local data out of Git.
- `.gitattributes`: Gives Git consistent line endings and treats binary documents as binary.
- `.env.example`: Documents local configuration keys without storing credentials.
- `pyproject.toml`: Defines Python metadata, runtime dependencies, development tools, lint rules, type checking, and test settings.
- `uv.lock`: Generated by `uv`; pins the complete Python dependency graph for reproducible installs.
- `Makefile`: Provides short, consistent commands for installation, checks, development, and infrastructure.
- `README.md`: The entry point for setup and the current milestone.

## Applications and packages

- `apps/api/main.py`: Creates the FastAPI application and exposes liveness/readiness endpoints.
- `apps/api/config.py`: Loads typed settings from environment variables.
- `apps/worker/celery_app.py`: Creates the Celery application boundary; tasks are added in the ingestion phase.
- `packages/contracts/models.py`: Defines the first provider-neutral Pydantic contracts for provenance, queries, answers, and streaming events.

## Infrastructure and automation

- `infra/docker/docker-compose.yml`: Runs PostgreSQL, Redis Stack, and Qdrant locally. Langfuse is configured through environment variables because self-hosting it requires its official version-specific dependency bundle.
- `infra/docker/init.sql`: Creates the local PostgreSQL database extension baseline and is intentionally minimal until migrations are introduced.
- `.github/workflows/ci.yml`: Runs Python checks and the frontend type check on every push and pull request.
- `apps/web/package.json`: Defines the Next.js frontend dependencies and scripts.
- `apps/web/tsconfig.json`: Enables strict TypeScript checking.
- `apps/web/next.config.ts`: Holds Next.js configuration.
- `apps/web/app/layout.tsx`: Defines the root HTML shell and metadata.
- `apps/web/app/page.tsx`: Displays the current platform status while feature workflows are built.
- `apps/web/app/globals.css`: Provides the minimal global styles for the shell.
- `apps/web/.env.example`: Documents browser-safe frontend configuration.

## Why contracts come first

The API, worker, retrieval system, graph, and UI will evolve independently. Typed contracts make those boundaries explicit and preserve document/page/region provenance before any model or vector database implementation is introduced.
